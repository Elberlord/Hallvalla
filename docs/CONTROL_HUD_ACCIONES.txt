CONTROL DEL HUD DE ACCIONES
===========================

Se agregó un editor exclusivo para el HUD de acciones.

Abrir:
- Durante la batalla, pulsa el engranaje.
- En Configuración, pulsa “Ajustar HUD de acciones”.

Controles:
- Tamaño: escala del grupo completo.
- Horizontal: desplazamiento izquierda/derecha.
- Vertical: desplazamiento arriba/abajo.
- Separación: espacio entre botones.
- Texto: tamaño de las etiquetas.

También puedes arrastrar directamente el grupo de botones mientras el editor está abierto.
Los valores se guardan en localStorage con la clave hallvalla_actions_hud_tuner_v1.
“Copiar valores” genera una línea lista para enviar con la configuración elegida.
