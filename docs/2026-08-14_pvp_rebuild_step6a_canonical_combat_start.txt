OBJETIVO 6A
- Después de arena_ready, únicamente J1 crea el estado oficial combatState.
- phase cambia a battle_active.
- combatState contiene un único Turno 1, activeRole, waitingRole y turnPhase=turn_start.
- Ambos clientes leen y renderizan exactamente ese estado de Firebase.
- actionsEnabled=false durante 6A: NO se activan aún fases avanzables, cartas, Honor, movimiento, ataques, casteos ni efectos.

- activeRole: 1 o 2 según el resultado previo
- waitingRole: rival
- turnPhase: turn_start
- actionsEnabled: false
- actionLockReason: STEP_6A_CANONICAL_START_ONLY

ECONOMÍA / APUESTAS
- Este subpaso NO descuenta oro ni transfiere cartas todavía.
- Para apuesta gratis: economy.state=not_required.
- Para oro/carta: economy.state=deferred_after_6a_validation.
- El cobro/retención se añadirá cuando se valide primero el arranque canónico; no se simula un cobro que todavía no sea atómico/recuperable.

SALIDA
- Si J2 abandona durante esta prueba, J1 devuelve la sala a waiting.
- Se limpian arenaBootstrap, combatState, startConfig, RPS y LISTO para evitar heredar un combate anterior.
