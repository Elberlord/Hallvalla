HallValla v7HW - PREC/EVA modal en DET

Cambios:
- El botón de regla en DET ahora usa el label compacto: PREC/EVA.
- El botón abre un modal con la fórmula actual:
  Precisión disponible = DX + AGI - stats gastados este turno.
  Evasión disponible = DX + AGI - stats gastados este turno.
- El modal explica que:
  - Atacar consume solo la precisión necesaria para superar la evasión disponible del objetivo.
  - Recibir ataques reduce más la evasión disponible.
  - Los stats gastados este turno se restauran al inicio del próximo turno del dueño.
  - Contra líderes el golpe impacta fijo, no consume precisión y la Guardia absorbe daño primero.
- También se actualizaron las ayudas de DX/AGI y el mini tutorial para no mostrar la fórmula vieja de porcentaje.
