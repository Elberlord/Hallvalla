HALLVALLA 7HEQ — LAYOUT DEDICADO PARA COMBATE MÓVIL HORIZONTAL

Cambios aplicados únicamente cuando JavaScript detecta un teléfono o dispositivo táctil en orientación horizontal mediante la clase hv-mobile-landscape.

- HUD superiores más compactos.
- Campo central recalculado con unidades dinámicas del viewport.
- Líderes reducidos aproximadamente al 70 % del tamaño móvil anterior.
- Estadísticas de líderes compactadas proporcionalmente.
- Honor reducido y reposicionado.
- Ajustes, Log y Acciones convertidos en una fila compacta inferior.
- Panel de Acciones desplazado a la derecha para liberar el centro.
- Mano de cartas más baja y con cartas de menor tamaño.
- Al abrir la mano, se ocultan visualmente Acciones y Log para impedir superposiciones.
- Variante adicional para teléfonos con menos de 380 px de altura útil.

No se modificó el layout de escritorio. Tampoco se cambiaron reglas, cartas, IA, Firebase, campañas, mapas ni estadísticas.
