HALLVALLA · MODELO CANÓNICO DE CARGA Y PENALIZACIÓN POR PESO · 20260908.12

PRINCIPIO
- La carga NO define el MOV base de una unidad.
- Un humano, un caballo, un elefante, una bestia y un dragón tendrán bases de locomoción distintas.
- Este sistema produce únicamente una PENALIZACIÓN DE CARGA (weightPenaltySteps).
- En esta build la penalización NO se aplica todavía a MOV. Se conserva como metadato interno.

CÁLCULO A PIE
carriedLoadKg = armadura + armas + escudo/equipo + misceláneos
effectiveLoadKg = carriedLoadKg × distributionFactor
burdenRatio = effectiveLoadKg / mobilityCapacityKg

CÁLCULO MONTADO
mountTotalLoadKg = masa del jinete + carga equipada + silla/arreos + armadura de montura
burdenRatio = mountTotalLoadKg / mountComfortLoadKg

UMBRALES
ratio <= 1.00 : penalización 0
1.00 < ratio <= 1.20 : penalización 1
1.20 < ratio <= 1.40 : penalización 2
ratio > 1.40 : penalización 3

NOTA DE DISEÑO
Los kilos son estimaciones internas basadas en la representación visual, equipo, constitución y naturaleza de cada unidad. No pretenden ser una reconstrucción histórica exacta. La capacidad representa carga tolerable SIN perder movilidad de combate, no la carga máxima que alguien podría transportar lentamente.
