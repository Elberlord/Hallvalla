Hallvalla - Splash visual de eventos de combate 7HCN
============================================================

ZIP base: Hallvalla_precision_spend_bug_7HCM.zip
ZIP generado: Hallvalla_event_splashes_7HCN.zip

Qué se agregó:
- Sistema de splash visual de eventos en el centro de la pantalla.
- Overlay nuevo en index.html:
  · #eventSplashOverlay
- Assets nuevos:
  · assets/ui/event_splashes/event_dodge.webp
  · assets/ui/event_splashes/event_guard.webp
  · assets/ui/event_splashes/event_bleed.webp
  · assets/ui/event_splashes/event_stealth.webp
  · assets/ui/event_splashes/event_burn.webp

Eventos conectados:
- ESQUIVA:
  se muestra cuando el juego emite dodgeFxEvent.
- GUARDIA:
  se muestra cuando hay guard_block (golpea pero no atraviesa la defensa).
- SANGRADO:
  se muestra en bleed_apply / bleed_refresh.
- EMBOSCADA:
  se muestra cuando el ataque sale desde Sigilo.
- QUEMADURA:
  se muestra en burn_apply.

Comportamiento:
- Aparece en el centro de la pantalla.
- Se mantiene unos 3 segundos.
- Sale con fade out suave.
- Si llegan varios eventos seguidos, se encolan y se muestran uno detrás de otro.
- No bloquea clicks ni la interfaz.

Cambios de código:
- makeBattleFxEvent() ahora puede incluir stealthAttack.
- maybePlayBattleFx() ahora también decide los splashes a partir de:
  · explicitAttackFx
  · explicitDefenseFx
  · explicitDodgeFx
  · explicitStatusFx
- Se limpia el overlay al salir o reiniciar batalla.

No se tocó:
- Balance.
- IA.
- Fórmulas de daño.
- Sonidos.
- Rarezas.
- Aros de convocación.
- FX de invocación.
- Cartas, mapas o mazos.

Verificación:
- script.js node --check: OK

- CSS balance de llaves: OK
