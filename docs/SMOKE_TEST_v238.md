# HallValla v238 — Smoke test desconexión PvP

1. Entrar con dos cuentas distintas a un PvP humano y llegar a combate activo.
2. Matar al menos una unidad antes de desconectar para comprobar que la baja se conserva.
3. En J2 (o J1), usar Salir durante combate o cerrar la pestaña/conexión.
4. El rival debe recibir el aviso **Rival desconectado**.
5. Ranking: el que salió pierde 2 puntos y suma 1 derrota; el que quedó no suma victoria ni puntos.
6. Repetir invirtiendo J1/J2.
7. Repetir saliendo antes de `active`: no debe existir penalización.
8. Verificar que la sala y private/playerN no queden bloqueando un matchmaking posterior.
