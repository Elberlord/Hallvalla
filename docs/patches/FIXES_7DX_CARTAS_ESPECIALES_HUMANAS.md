# HallValla v7DX - Cartas especiales humanas

- Se añadieron al catálogo todas las cartas especiales humanas del PDF `HallValla_personajes_humanos_v1`.
- Las cartas especiales quedan con key, nombre, rareza, costo, stats, icono, retrato `.webp` temporal y texto de efecto.
- Los efectos quedan como texto/base de diseño; la implementación mecánica completa se revisará luego carta por carta.
- La lista de especiales de Aquiles ahora referencia `ALL_SPECIAL_CARD_KEYS` para usar el nuevo pool completo de especiales.
- El token `Caballería Arquera de Saladino` queda definido como token asociado, no como carta normal del mazo.
