# HallValla v0.7BO - Detail Stat Guide

Cambios:

- El modal de detalle ahora incluye una guía rápida de estadísticas.
- Cada stat muestra una explicación breve: Costo, AT, HP, GD, DX, MV, RG y Daño.
- Las unidades inspeccionadas desde el tablero también muestran la guía rápida.
- La mano queda minimalista: unidades muestran nombre, costo, AT y HP; magia/trampa solo nombre y costo.
- El texto completo de la carta y su efecto se conserva únicamente en el detalle.
