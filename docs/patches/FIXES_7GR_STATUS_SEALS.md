# FIXES_7GR_STATUS_SEALS
- Reemplazo visual de burbujas de estado por sellos mágicos integrados al marco de la carta.
- Sellos distribuidos a izquierda/derecha para no tapar el retrato.
- Colores por categoría (buff, debuff, sangrado, veneno, silencio, etc.).
- Indicador pequeño para valores numéricos cuando aplica (+/- cantidad).
- Si hay más estados de los que caben, se muestra un contador adicional `+N`.
