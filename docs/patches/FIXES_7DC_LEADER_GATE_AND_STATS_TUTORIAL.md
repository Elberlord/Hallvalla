# HallValla v7DC — Líder obligatorio y mini tutorial de stats

## Cambios
- El Home sigue siendo clickeable.
- Antes de entrar a Aventura u Online, el juego exige elegir líder si aún no hay uno.
- Después de elegir líder por primera vez, aparece un mini tutorial de stats antes del primer modo jugable.
- El tutorial explica HP, AT, GD, DX, AGI, MV, RG y Costo/Honor.
- El tutorial recuerda el alcance correcto de los líderes:
  - Guerrero: solo infantería pesada.
  - Arquero: solo arqueras.
  - Hechicero: solo magias.
- Se agregó en Configuración el botón “Ver mini tutorial de stats” para poder abrirlo de nuevo.
