# HallValla v7DH — Ajuste visual de historia: héroes y texto

## Problema
En la escena “Dos leyendas responden”, Mulan quedaba detrás del bloque de texto.

## Cambios
- Mulan y William Wallace se reposicionan hacia los lados.
- El texto queda centrado entre ambos héroes.
- Los héroes tienen mayor prioridad visual para quedar al frente de la composición.
- El texto crece ligeramente y tiene más interlineado para que sea más cómodo de leer.
- Se agregaron ajustes responsive para tablets y móviles.
