HallValla v31 · Fase de calibración de iconos DET

Esta compilación NO conecta todavía los iconos a los datos dinámicos de cada unidad.
Los 18 iconos de assets/ui/det_icons se muestran como objetos independientes para acomodarlos una sola vez.

Uso:
1. Abre cualquier DET.
2. Pulsa AJUSTAR DET. La edición directa se activa automáticamente.
3. Haz clic y arrastra cualquier icono con el mouse.
4. La rueda del mouse cambia la escala del objeto seleccionado.
5. Pulsa COPIAR JSON ICONOS.
6. Pasa ese JSON para convertir esas posiciones en el layout definitivo.
