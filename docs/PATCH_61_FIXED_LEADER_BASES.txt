Patch 61 - Fixed leader bases

Goal:
- Move leaders out of the central board presentation and render them as fixed Base Norte / Base Sur pieces.
- Leaders still attack, defend, keep DET/EFFECT/modal/status interactions, and keep their range.
- Leaders cannot move.

Touched:
- script.js
  - Leaders are no longer rendered as ordinary board unit-cards inside cells.
  - Added a leader bases layer rendered over the battlefield.
  - Added clickable Base Norte / Base Sur leader tokens.
  - Leader base clicks still route targeting, DET/context menu, DEF, ATTK, EFFECT.
  - effectiveMov() returns 0 for leaders.
  - isUnitMoveWindow() blocks leader movement.
  - moveUnit() refuses leader movement with a clear hint.
  - AI no longer tries to move its leader, but can still attack or use DEF.
- styles.css
  - Added visual layout for fixed 3D-style leader bases.

Not touched:
- Unit stats.
- Damage formulas.
- Defense logic.
- Attack range logic.
- Normal unit movement.
- Cards/decks.
- Phase system.
