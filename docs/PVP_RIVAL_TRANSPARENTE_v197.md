# HallValla v197 - Rival transparente

El sistema puede usar un rival automatizado cuando no encuentra otro jugador, pero la experiencia normal no lo anuncia.

UI de matchmaking:
- BUSCANDO RIVAL...
- RIVAL ENCONTRADO

No se muestran etiquetas BOT, mensajes de fallback, reintentos BOT ni nombres con sufijo BOT.
La identificación interna sigue existiendo únicamente para reglas, resultados, exclusión del ranking y depuración.
