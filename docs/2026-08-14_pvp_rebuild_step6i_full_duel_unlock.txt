HALLVALLA · PVP REBUILD · PASO 6I · DUELO COMPLETO

BASE: Paso 6H Fireball + Quemadura, validado por el usuario.

OBJETIVO
- Eliminar las limitaciones de prueba por familia de mecánica.
- Mantener el motor real usado por PvE como única lógica de combate.
- Mantener sincronización PvP por Firebase y commits multipath para acciones que combinan estado público + privado.
- Permitir una partida completa hasta victoria/derrota.

HABILITADO
- INVOCAR / MOV / DEF / ATTK / EFFECT.
- Unidades, magias, equipos y trampas del mazo real.
- Pasivos, triggers, estados persistentes, Splash Events y FX existentes.
- Fases, cambio de turno, manos privadas, Honor, muerte de unidades y condición de victoria del motor real.
- Timer del host: deja de estar suspendido en builds de prueba; si Timer=ON usa el reloj real existente.
- Perspectiva local: cada jugador se ve al sur y avanza hacia el norte; Firebase conserva coordenadas canónicas únicas.

CAMBIOS DE PRUEBA RETIRADOS
- Fireball ya NO se fuerza en la primera mano.
- La mano vuelve a salir del mazo guardado normal.
- Se desactiva el gate STEP6F_LIMITED para estados pvpFullDuelEnabled.

ECONOMIA / APUESTAS
- Para la primera prueba integral usar Apuesta=Gratis.
- El selector de apuesta se conserva, pero la liquidación económica de apuestas (oro/carta) sigue marcada como pending_economy_validation y NO debe considerarse validada por este paso.
