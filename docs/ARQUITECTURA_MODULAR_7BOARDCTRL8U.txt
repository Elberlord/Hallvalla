ARQUITECTURA
- index.html carga únicamente js/bootstrap-loader.js como módulo ES.
- bootstrap-loader.js importa Firebase una sola vez y expone sus funciones al entorno global.
- Los 16 archivos de js/parts/ se cargan secuencialmente como scripts clásicos estrictos.
- El orden original del código fue conservado para mantener las dependencias entre const, let y funciones.
- script.js queda como archivo legado mínimo y ya no se ejecuta.
