HallValla - Eliminación de cura duplicada 7HEE
==============================================

Base usada:
- Hallvalla_craft_materials_visible_7HED.zip

Problema:
- Existían dos cartas con la misma función:
  1. healing_light / Luz de sanación
  2. heal / Heal
- Ambas curaban 3 HP, costaban 2 y usaban spell:"heal".

Cambio aplicado:
- Se eliminó la carta vieja duplicada:
  - key: healing_light
- Se conservó la carta real del sistema de packs/forja:
  - key: heal
  - asset: assets/cards/basic/heal.webp
- La carta conservada fue renombrada visualmente:
  - de "Heal"
  - a "Luz de sanación"

Resultado:
- Ahora solo existe una cura básica.
- El starter y los packs pueden seguir usando key:"heal" sin romper nada.
- En la UI el jugador verá "Luz de sanación", no "Heal".

No se tocó:
- Costos de creación
- Forja de materiales
- Combate
- IA
- Cartas vikingas
- Cartas ninja
- Cartas samurái
- Packs, salvo eliminar el duplicado viejo del pool normal
