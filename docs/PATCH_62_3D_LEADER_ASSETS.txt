PATCH 62 - 3D LEADER ASSETS

Objetivo:
Conectar los nuevos PNG 3D de líderes ubicados en assets/leaders/ al sistema visual de HallValla.

Cambios aplicados:
- Se crearon nombres normalizados para código:
  leader_warrior_3d.png
  leader_archer_3d.png
  leader_mage_3d.png
  leader_axe_3d.png
  leader_cavalry_3d.png
  leader_assassin_3d.png
  leader_beastmaster_3d.png
- LEADER_PORTRAITS ahora apunta a los PNG 3D nuevos.
- La pantalla de selección de líder usa los PNG 3D nuevos.
- Las Bases Norte/Sur renderizan estos líderes como fichas completas con object-fit: contain para no cortar cuerpo, arma ni pedestal.
- Se añadió clase visual por tipo de líder en base fija para ajustes específicos, especialmente caballería.
- Se ajustó tamaño y posición de bases fijas para acomodar mejor fichas altas.
- Se limpió/procesó el warrior para obtener una versión PNG con transparencia real, porque el archivo original venía RGB con fondo tipo checkerboard.

No se tocó:

- IA general.

- Unidades normales.
- Cartas.
