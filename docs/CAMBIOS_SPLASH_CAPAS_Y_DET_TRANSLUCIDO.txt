CAMBIOS APLICADOS
=================

1) SPLASHES DE EVENTO EN CAPAS
- El splash ahora usa varias capas visuales para que no se vea plano.
- Se agregó sombra base independiente por debajo del splash.
- Se agregó glow de profundidad dentro del panel.
- Se agregó sheen/brillo superior suave sobre el panel.
- Se mantuvo el tamaño tipo carta y la retirada lateral.

2) ICONO DEL SPLASH CON RELIEVE PROPIO
- Cada splash ahora muestra un icono montado en una placa circular.
- El icono queda sobresalido por encima del panel principal.
- La placa tiene borde, glow y sombra propios.
- El icono entra con una microanimación independiente.
