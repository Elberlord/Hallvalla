Hallvalla - Separación de splash por evasión parcial/agotada 7HDF
====================================================================

ZIP base: Hallvalla_sound_modal_resize_7HDE.zip
ZIP generado: Hallvalla_evasion_split_splash_7HDF.zip

Cambio aplicado:
- Se separó el resultado visual cuando un ataque falla por evasión.
- Ahora el splash depende de cuánta evasión le queda al defensor después de resolver el ataque.

Nueva regla visual:
1) Si el defensor evade y NO consume toda su evasión:
   -> splash de ESQUIVA.
   -> ejemplo: gastó 2, le quedan 3.

2) Si el defensor evita el golpe pero consume TODA su evasión:
   -> splash de GUARDIA / BLOQUEO.
   -> representa un bloqueo de último recurso, no una esquiva limpia.
   -> ejemplo: gastó 4, le quedan 0.

3) Si el ataque sí acierta y pega contra Guardia:
   -> se mantiene splash de GUARDIA normal.

Implementación general:
- Se agregaron helpers:
  · isEvasionExhaustedBlock(evasionPressure)
  · makeMissDefenseFxEventByEvasion(defender,evasionPressure)
  · makeCleanDodgeFxEvent(defender,evasionPressure)
- Aplica tanto para:
  · ataques del jugador
  · ataques de IA
- No se hizo por unidad. Es regla visual general.

Notas:
- Esto evita que una evasión parcial muestre escudo.
- Si la unidad queda sin reserva de EVA al salvarse, entonces sí se ve escudo/bloqueo.
- La prioridad 7HDB se mantuvo, pero ahora permite el caso intencional:
  combatResult: "evasion_exhausted_block"
