FIX SPLASHES VISUALES INVISIBLES
================================

CAUSA PRINCIPAL
---------------
La regla final de CSS dejaba `.event-splash-shell` con:

- `opacity: 0 !important`
- `transform: ... !important`
- un `filter` posterior también marcado como `!important`

Las animaciones sí se activaban y el JavaScript sí generaba los eventos,
pero una animación CSS no puede sobrescribir declaraciones de autor con
`!important`. Por eso el splash permanecía invisible durante toda su vida.

CORRECCIONES
------------
1. Se quitaron los `!important` únicamente de las propiedades animadas del
   splash: opacity, transform y filter.
2. Se mantuvieron la entrada, el tamaño tipo carta, las capas, el icono
   elevado y la retirada lateral.
3. GUARDIA ahora se activa tanto en `guard_block` como en `guard_break`.
   Antes, si el golpe rompía Guardia y también atravesaba HP, el evento visual
   existía pero el splash no se agregaba a la cola.
4. Parálisis y shock se normalizan al splash ATURDIDO.
5. Silencio y maldición se normalizan al splash DEBILITADO mientras no exista
   una imagen exclusiva para esos estados.

VERIFICACIONES
--------------
- Guardia bloqueada -> splash GUARDIA.
- Guardia rota -> splash GUARDIA.
- Evasión limpia -> splash ESQUIVA.
- Sangrado -> splash SANGRADO.
- Quemadura -> splash QUEMADURA.
- Veneno -> splash VENENO.
- Miedo -> splash MIEDO.
- Aturdimiento/parálisis/shock -> splash ATURDIDO.
- Debuff/silencio/maldición -> splash DEBILITADO.
- Las 9 imágenes de event_splashes siguen presentes.
- script.js pasa `node --check`.
