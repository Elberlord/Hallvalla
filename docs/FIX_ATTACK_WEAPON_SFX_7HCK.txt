Hallvalla - Ataques por tipo de arma y sonido de fuego/mago 7HCK
============================================================

ZIP base: Hallvalla_replace_map_icons_7HCI.zip
ZIP generado: Hallvalla_attack_weapon_sfx_7HCK.zip

Audio creado / reemplazado:
- assets/sfx/guard_block.ogg
  Sonido genérico de arma chocando contra escudo cuando el ataque no atraviesa Guardia.
- assets/sfx/attack_fire_magic.ogg
  Sonido breve tipo lanzallamas/chorro de fuego mágico, duración aproximada 1.08 s.

Audio existente conectado:
- assets/sfx/attack_slash.ogg
  Ahora se usa como golpe cuerpo a cuerpo genérico.
- assets/sfx/attack_ranged.ogg
  Ahora se usa para flechas / ataques de arquero.

Cambios en script.js:
- getUnitWeaponKind() ahora detecta:
  · fire_magic para magos, arcano, fuego, llamas o iconos mágicos.
  · arrow para arqueros, Simo, icono de arco o rango muy alto.
  · spear / axe / sword según arma.
- getAttackSoundForUnit() ahora asigna:
  · fire_magic → attack_fire_magic
  · arrow → attack_ranged
  · spear → attack_spear
  · axe → attack_axe
  · melee genérico → attack_slash
  · demigod → attack_demigod
- Fireball ahora usa attack_fire_magic.
- Otros hechizos de daño mantienen spell_damage.
- guard_block subió un poco de volumen para que el choque arma/escudo se sienta mejor.

No se tocaron:
- Reglas, fases, mazos, IA o balance.
- CSS visual.
- Aros de convocación.
- FX visuales de invocación.
- Brillo de rarezas.
- Cartas, mapas o UI.
