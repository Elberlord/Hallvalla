Patch 60 - Enemy DET modal click fix

Problem:
- In DET for enemy AI units/leaders, guide icons did not open their explanation modal.
- This affected Conóceme, PREC/EVA, ability icons, stat icons and active status icons.

Fix:
- Added an inspector-level delegated click/pointerup handler for the DET modal.
- Stored the currently inspected entity and its active statuses on the inspector element.
- Added CSS pointer-event shielding so DET buttons stay clickable even with the premium layout overlays.

Untouched:
- Combat rules
- IA decisions
- Stats
- Damage
- Movement
- Defense/guard calculations
- Card data
