HallValla - Fix visual de materiales de creación 7HED
=====================================================

Base usada:
- Hallvalla_deep_audit_clean_7HEC.zip

Problema:
- En la Forja no quedaba claro ni visible cuánto material tenía el jugador para crear cartas.
- El panel existía, pero estaba escondido en el lateral y las mini-cartas solo mostraban el dato en el tooltip del botón de crear.

Cambios aplicados:
1. Se agregó un wallet visible de materiales en la cabecera de la Forja:
   - id="craftMaterialSummary"
   - Muestra Básica, Épica, Gloriosa, Mítica, Legendaria y Semidiós.
   - Cada rareza muestra: material actual / costo de creación.

2. Se reforzó el panel lateral:
   - Ahora se titula "Materiales para crear cartas".
   - Muestra total de materiales.
   - Cada rareza muestra cuánto tienes y cuánto cuesta crear.

3. Se agregaron etiquetas visibles en las mini-cartas:
   - Ejemplo: "Básica: 250/800"
   - Ya no depende solo del tooltip.
   - Si tienes material suficiente, se marca visualmente.

4. Se actualizó cache-buster:
   - script.js?v=craft-materials-7hed
   - styles.css?v=craft-materials-7hed

No se tocó:
- Combate

- cartas vikingas
- cartas samurái
- cartas ninja
- sistema de packs
- sistema de colección
- costos de creación
- conversión de sobrantes
