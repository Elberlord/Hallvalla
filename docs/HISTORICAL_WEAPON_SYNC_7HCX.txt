===================================================================

ZIP base: Hallvalla_det_weapon_modal_7HCW.zip

OBJETIVO
--------
Revisar la carpeta assets y alinear clase táctica + retrato con el arma o rol histórico más icónico de cada unidad cuando había una discordancia clara.

CAMBIOS DE CÓDIGO
-----------------
1) Se integró la clase táctica Hacha en la rueda de armas:
   - sword > spear
   - spear > cavalry
   - cavalry > bow
   - bow > axe y beast
   - axe > sword
   - beast > cavalry

2) Se añadió:
   - etiqueta Hacha / dos manos
   - icono weapon_axe.png
   - soporte DET / guía / textos para Hacha

3) Se corrigieron clases históricas:
   - Berserker del norte: sword -> axe
   - Boudica: sword -> spear
   - Ulises / Odiseo: sword -> bow
   - Ragnar Lodbrok: sword -> axe
   - Gengis Kan: sword -> cavalry

4) Se ajustó el reconocimiento de líder de hacha:
   - leaderType axe ahora muestra axe, no sword

5) Se corrigieron textos visibles:
   - rueda táctica actualizada con Hacha
   - descripciones de lanza visibles alineadas con Atacar Primero

CAMBIOS DE RETRATO
------------------
Se reemplazaron retratos cuando sí era necesario para acercarlos al arma/rol icónico:
- Ulysses / Odiseo:
  retrato cambiado para que aparezca con arco/arquero heroico mediterráneo,
  alineado con el arco que inmortaliza el regreso a Ítaca.
- Genghis Khan:
  retrato cambiado para mostrarlo como caudillo montado con arco compuesto,
  alineado con su rol histórico más icónico de caballería de estepa.

- Boudica ya mostraba lanza/escudo
- Ragnar ya mostraba hacha
