# HallValla V1 Local Clean Core

Este build es una base local de prueba.

Incluye:
- Home local
- Campo 7x5
- Líderes 3D fijos fuera del grid
- Unidades normales
- DEF como estado lógico + sello visual
- FX seguro, pequeño, sin overlays de tablero
- Sin Firebase
- Sin script viejo
- Assets actuales

Objetivo:
Validar que DEF no genera óvalos, cuadros gigantes ni desplazamientos de líderes.
