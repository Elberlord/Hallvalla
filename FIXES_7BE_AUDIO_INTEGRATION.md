# FIXES 7BE — AUDIO INTEGRATION

## Nuevo
Se integró el pack `hallvalla_audio_pack_v1` directamente al juego.

## Carpetas agregadas
- `assets/sfx/`
- `assets/music/`

## SFX conectados
- Botones: `button_click`
- Selección de cartas: `card_select`
- Jugar carta: `card_play`
- Draw Phase / robo: `draw_card`
- Carga de Honor/Mana: `mana_charge`
- Cambio de fase: `phase_change`
- Invocación básica: `summon_basic`
- Invocación heroica / épica / mítica: `summon_heroic`
- Invocación gloriosa: `summon_glorious`
- Invocación semidiós: `summon_demigod`
- Ataque normal: `attack_slash` + `attack_impact`
- Ataque heroico/rareza alta: `attack_heroic` + `attack_impact`
- Ataque semidiós: `attack_demigod` + `attack_impact`
- Hechizos: `spell_cast` / `spell_damage`
- Trampas: `trap_trigger`
- Victoria: `victory`
- Derrota: `defeat`

## Música conectada
- Home: `home_theme_loop`
- Duelo normal: `duel_theme_loop`
- Duelo boss / aventura avanzada: `boss_duel_theme_loop`

## Menú
- El botón del menú de duelo ahora activa/desactiva todo el audio.
- El navegador puede requerir un primer click/toque antes de dejar sonar música, eso es normal.

## Nota
El pack es procedural/original y sirve como primera base de prueba. Cualquier archivo puede reemplazarse luego manteniendo el mismo nombre.
